# mastra-pattern-parallel — 并行模式：三位评审 parallel 并发 → merge 汇总

## 演示内容

并行模式：三位评审 parallel 并发 → merge 汇总。

```bash
cd ai/mastra/mastra-patterns/mastra-pattern-parallel
npm install
cp .env.example .env   # 填入 DEEPSEEK_API_KEY
npx tsx src/demo.ts    # 程序化演示
npx mastra dev         # 或启动 dev server + Studio
```

> 与其他组 parallelization 1:1 对照。已运行验证。
