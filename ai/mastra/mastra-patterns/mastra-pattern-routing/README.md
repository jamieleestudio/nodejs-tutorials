# mastra-pattern-routing — 路由模式：结构化分类 → branch 分发三路专家

## 演示内容

路由模式：结构化分类 → branch 分发三路专家。

```bash
cd ai/mastra/mastra-patterns/mastra-pattern-routing
npm install
cp .env.example .env   # 填入 DEEPSEEK_API_KEY
npx tsx src/demo.ts    # 程序化演示
npx mastra dev         # 或启动 dev server + Studio
```

> 与 java 侧四个组的 routing 1:1 对照。已运行验证。
